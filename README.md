# Hub Carbon — GitHub Pages

Production-ready static site for Hub Carbon. The homepage preserves the original V1 visual system; production refinements include SVG infrastructure icons, favicon, institutional footer and Formspree contact form.

## Contact form
The contact form uses Formspree endpoint `https://formspree.io/f/xppzgddy`. In Formspree, set the form Target Email to the verified `info@hubcarbon.com` address. Current Formspree workflow: Form → Workflow → Email → Settings.

## GitHub Pages
Publish from `main` / root. The CNAME file contains `www.hubcarbon.com`. Do not change DNS until the GitHub Pages preview and contact form have been tested.
